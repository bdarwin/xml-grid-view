View and edit XML and JSON as a tree, a spreadsheet-like grid of repeating elements or array items, or a Flat outline sheet, right next to the text editor. Edit cells in place, paste rows from Excel or Google Sheets, export CSV, search with text, regex or XPath, and see validation errors in the grid.

  • Grid tab: a tree of elements (key attributes, child counts, speed search and a node filter) beside a grid of repeating children. Columns are attributes, text-only children and mixed text, and nested repeats appear as {tag ×n} cells you can drill into, with breadcrumbs back up. A summary above the grid shows the element's own attributes and values, editable in place.
  • Flat tab: the whole document as a Name / Value outline sheet with attribute rows, collapse/expand, spreadsheet-style cell selection and copy as TSV.
  • Sorting, per-column filters (text and a distinct-values checklist), row numbers, grid lines and theme colors.
  • Edit values: select an attribute value or a leaf element's text and press F2, or just type. Enter commits. Values are escaped automatically and CDATA is preserved, and every edit is a normal, undoable change.
  • Edit structure from the context menu of the tree, grid or Flat view: insert child, before or after, duplicate, rename, add or delete attributes, and delete elements. Formatting and indentation are kept, names are validated, and each edit is one undo step.
  • Value inspector (double-click or Shift+Enter): long text in full, plus JSON as a Tree, a drill-down Grid or pretty Text. Large numbers are shown exactly, and the value can be edited and saved, with JSON validation.
  • Find (Ctrl/Cmd+F): match case, whole word and regex, over the current grid or the whole document, with a results list and "show only matches". XPath mode binds document prefixes automatically, with the default namespace as d:.
  • Spreadsheet-style grid editing: insert, move and delete rows, add and delete columns, clear cells, and paste blocks from a spreadsheet (extra rows become new elements). Export as CSV or JSON.
  • JSON files (.json, .jsonc, .geojson): arrays of objects become grids; members and items can be added, renamed, moved and deleted, and value types are kept.
  • Problems: the IDE's XML Schema and DTD validation errors are marked in the tree and grid.
  • Follows edits in the text editor and keeps expansion, selection, sort and filters. Malformed XML keeps the last valid view and shows a banner that links to the error.

Open any .xml or .json file and use the Text | Grid | Flat tabs at the bottom of the editor. Enter/F4 jumps to the element in the text. In Remote Development, install the plugin on the host.
