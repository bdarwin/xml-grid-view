View and edit XML as a tree, a grid of repeating elements, or a Flat outline sheet, right next to the text editor. Includes text, regex and XPath search, a value inspector with JSON support, and in-place editing of values.

  • Grid tab: a tree of elements (key attributes, child counts, speed search and a node filter) beside a grid of repeating children. Columns are attributes, text-only children and mixed text, and nested repeats appear as {tag ×n} cells you can drill into, with breadcrumbs back up.
  • Flat tab: the whole document as a Name / Value outline sheet with attribute rows, collapse/expand, spreadsheet-style cell selection and copy as TSV.
  • Sorting, per-column filters (text and a distinct-values checklist), row numbers, grid lines and theme colors.
  • Edit values: select an attribute value or a leaf element's text and press F2, or just type. Enter commits. Values are escaped automatically and CDATA is preserved, and every edit is a normal, undoable change.
  • Value inspector (double-click or Shift+Enter): long text in full, plus JSON as a Tree, a drill-down Grid or pretty Text. Large numbers are shown exactly, and the value can be edited and saved, with JSON validation.
  • Find (Ctrl/Cmd+F): match case, whole word and regex, over the current grid or the whole document, with a results list and "show only matches". XPath mode binds document prefixes automatically, with the default namespace as d:.
  • Follows edits in the text editor and keeps expansion, selection, sort and filters. Malformed XML keeps the last valid view and shows a banner that links to the error.

Open any .xml file and use the Text | Grid | Flat tabs at the bottom of the editor. Enter/F4 jumps to the element in the text. In Remote Development, install the plugin on the host.
