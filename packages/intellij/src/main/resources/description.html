A read-only XML viewer that adds a tree and a grid next to the text editor, with text, regex and XPath search.

  • Tree of elements, with key attributes, child counts and speed search. Enter/F4 jumps to the element in the editor.
  • Grid of repeating child elements. Columns are attributes, text-only children and mixed text. Nested repeats appear as {tag ×n} cells you can drill into. Breadcrumbs lead back up, and there's a tag-group selector.
  • Sorting, per-column filters (text and a distinct-values checklist), row numbers, multi-cell selection and copy as TSV.
  • Find (Ctrl/Cmd+F): match case, whole word and regex; search the current grid or the whole document by names, attributes and text; a results list and a "show only matches" tree filter. XPath mode binds document prefixes automatically, with the default namespace as d:.
  • Follows edits in the text editor and keeps expansion, selection, sort and filters. Malformed XML keeps the last valid view and shows a banner that links to the error.

Open any .xml file. Then click the Grid tab at the bottom of the editor (Text | Grid); Enter/F4 in the grid jumps back to the text. The plugin never modifies the document.
